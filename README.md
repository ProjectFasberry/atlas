## Fasberry Monorepo

Welcome to the Fasberry Monorepo, the primary client-side codebase for the Fasberry web landing, app and wiki.

This repository contains three primary apps:
- Taurus - [landing](https://fasberry.fun)
- Minotaur - [app](https://app.fasberry.fun)
- Wiki - [wiki](https://wiki.fasberry.fun)
