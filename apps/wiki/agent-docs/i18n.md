# Languages and translation

The UI uses [Paraglide](https://inlang.com/m/gerre34r/library-inlang-paraglideJs).
Messages live in `messages/ru.json` and `messages/en.json`; Russian is the base
locale and the fallback. The locale comes from the `locale` cookie, then
`Accept-Language`, and `proxy.ts` stores the detected language in that cookie for
the next visit.

Content from the database is not translated. `pnpm translate:content` fills
`wiki_page_translations` (MyMemory, free, no key); the site serves a translation
only while its `source_hash` still matches the Russian page and falls back to
Russian otherwise. `--force` re-translates, `--slug <slug>` limits the run.
