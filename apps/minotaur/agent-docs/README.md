# Agent-readable docs

Focused rules for writing minotaur code. Start at
[`../AGENTS.md`](../AGENTS.md), then open the topic you need.

| File | Read it when |
| --- | --- |

| [`models.md`](./models.md) | Adding state, async data, forms or mutations. |
| [`data-api.md`](./data-api.md) | Calling the API or using generated types. |
| [`ui-styling.md`](./ui-styling.md) | Choosing UI primitives, Tailwind classes, dialogs or tables. |
| [`routing-auth.md`](./routing-auth.md) | Adding a private page, guard, permission or sidebar link. |
| [`i18n.md`](./i18n.md) | Adding user-facing text or a locale key. |
| [`checks-deploy.md`](./checks-deploy.md) | Running checks, regenerating files or deploying. |
| [`examples.md`](./examples.md) | Copying a canonical page/model/component shape. |
