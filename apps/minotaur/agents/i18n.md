# Internationalization

Minotaur uses Paraglide (inlang). Russian is the base locale; English is the
second locale.

## Files

| Path | Role |
| --- | --- |
| `messages/ru.json` | Base locale strings. |
| `messages/en.json` | English strings. |
| `project.inlang/settings.json` | Locales and message-format plugin. |
| `paraglide/` | Generated output; never edit. |
| `shared/locales/helpers.ts` | Exports `translate` (alias of paraglide `m`). |

Add a new string to **both** locale files with the same nested key structure.

## Usage

```ts
import { translate } from "@/shared/locales/helpers";

const title = translate["servers.page.title"]();
const count = translate["servers.online"]({ count: String(n) });
```

- Keys are nested JSON paths; call the generated function.
- Paraglide is type-safe: a missing key is a type error.
- The generated `paraglide/` output is produced by the Vite plugin on dev/build;
  do not import from a hand-written path.
- `getLocale()` / `setLocale()` from `@/paraglide/runtime` are for the language
  switcher only.
- `LOCALES_MAP` in `shared/locales/index.ts` is the display-name map.

## Rules

- No user-facing string in JSX, models or toasts; put it in the locale files.
- Use the same key in both locales; do not leave an English fallback in `ru.json`
  or vice versa.
- Keep keys grouped by feature (`servers.*`, `store.*`, `private.*`).
- Do not edit `paraglide/` or the generated message modules.
- When a new key is added, run the app's dev/type-check so Paraglide regenerates;
  `pnpm --filter minotaur type-check` includes the sprite patch but the message
  modules are produced by Vite (dev/build). If the type-check runs before a
  build, run `bun --bun run vike build` or `vike dev` once.
- `gen:translate` (`inlang machine translate`) is for bulk translation; review
  the output before committing.
